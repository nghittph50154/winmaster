# sources/drivers/

Place your fixed driver files here.

Expected files:
- Pattern YINDIAO-G17 (e.g., YINDIAO-G17-Drive.zip)
- Pattern Inphic (e.g., Inphic-Drive.zip)
- Pattern AULA-F87 (e.g., AULA-F87-Pro-Drive.zip)

If a file is a ZIP/7Z/RAR archive, WinMaster will:
- Copy it to your Downloads folder
- Display the path
- Ask you to extract and install manually
